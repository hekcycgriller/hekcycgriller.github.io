# MemoCards PRO — web version

## Размещение в интернете

Эта папка — готовый статический сайт. Главный файл называется `index.html`.

Подходит любой статический хостинг. Например, GitHub Pages.

1. Создайте репозиторий на GitHub.
2. Загрузите **все содержимое этой папки** в корень репозитория.
3. Включите GitHub Pages для ветки `main` и папки `/root`.
4. Откройте выданный адрес сайта в Safari на iPhone.
5. Для режима приложения используйте Safari → «Поделиться» → «На экран Домой».

Не переименовывайте `index.html`, `manifest.webmanifest` и `sw.js`.

Карточки сохраняются в браузере устройства через localStorage. Экспортируйте JSON, если хотите иметь резервную копию или переносить набор на другое устройство.
